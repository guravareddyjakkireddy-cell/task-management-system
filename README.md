# Task Management System

## Project Overview
A simple Task Management System with authentication, task assignment, and tracking features.

## Features
- Login Authentication
- Create & Assign Tasks
- Track Task Status
- Backend API Integration

## Tech Stack
- Frontend: HTML, JavaScript
- Backend: Node.js (Express)
- Database: MySQL (Schema provided)

## How to Run

### Backend
cd backend
npm install
npm start

### Frontend
Open index.html in browser
